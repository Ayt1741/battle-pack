## Что уже найдено (проверь сам и скажи, что не так)

1. Главная находка совета (хода 56 и 57): работа arXiv **2606.13174** «Getting Better at Working With You: Compiling User Corrections into Runtime Enforcement for Coding Agents» — механизм **Trace**. Правила пользователя компилируются в ПРОВЕРКИ (applicability check + behavior instruction + verifier), которые обязаны пройти ДО завершения задачи. Цифры статьи: Mem0-память оставляет **57,5 %** применимых нарушений; Trace снижает нарушения со **100 % до 37,6 %** (в своей области) и до **2,0 %** (вне области). Механизм требует хуков (prompt/tool-use/file-write/termination); в Arena их НЕТ.
2. Код Trace: https://github.com/YujunZhou/TRACE_exp и https://github.com/YujunZhou/tellonce (проверь, что там лежит).
3. Среда у нас: Python 3.13 std-lib, файлы, bash, панель действий с цепочкой sha256, проверка ответа (10 детерминированных проверок), гейт (7 проверок). Платформенных хуков нет — все проверки запускает сам агент.
