# УРОКИ

Ошибки и как их не повторять. Дописываем, не стираем.

- **2026-10-18** Скриптовые «парсеры» для поиска в интернете запрещены. Только ручной обдуманный запрос к `web_search`, по одному.
- **2026-10-18** Разбор экспорта по пустым строкам дал 65 269 мусорных «моментов» вместо 1144. Разбирать только по маркерам роли (`## 👤 User` / `## 🤖 Assistant`), сравнивая токены, а не регуляркой с эмодзи.
- **2026-10-18** Хеш момента сначала включал время → при повторной сборке все 1144 момента записались второй раз, нумерация уехала до #2288. Время в хеш не включать, дедуп по содержимому.
- **2026-10-18** `walrus` внутри генератора списка — `SyntaxError`. В подобных местах писать циклом.
- **2026-10-18** Векторный поиск как единственный — проигрывает grep/BM25 на личных данных. Вектор только как дополнение к лексике (RRF).
- **2026-10-18** FTS5 не умеет опечатки: `trigram` ищет только подстроки от 3 символов, настоящего нечёткого поиска нет.
- **2026-10-18** Токенизатор вида `[а-яА-Я]{2,}` рвёт `v6.1` на куски — версии не находятся. Держать `[a-zа-я0-9]+(?:[.-][0-9]+)*`.
- **2026-10-18** Двойное хранение полного текста (таблица сообщений + таблица кусков + индекс) дало 85 МБ. Хранить текст один раз в журнале, индексировать только куски.
- **2026-10-18** Воркспейс упёрся в лимит снапшота (~128 МБ): старые артефакты вроде `.exe` на 37 МБ мешают сохраняться всей работе. Крупные нерегенерируемые файлы держать вне воркспейса.
- **2026-10-18** Маркером роли нельзя считать любую строку с эмодзи: «## AI Providers», «## 🤖 Ответ 2», «## 👤 Пользователь 1» — это заголовки ВНУТРИ ответов. Из-за них память показывала 1144 момента вместо 1128. Правило: ровно `##`, ровно одно-два слова избелого списка (User/Assistant/Пользователь/Ассистент/Human/Bot), без цифр.
- 2026-11-10 — Токенизатор: шаблон с (?:[.\-][0-9]+)* съедал начало хеша — sk-15658bcd… превращалось в sk-15658 + bcd…, и запрос по ключу не находил запись. Дефис в шаблоне версии убрать, оставить только точки; для длинных токенов добавить запасной LIKE.
- 2026-11-10 — Метрика recall на общих словах бессмысленна: 300 сообщений из начала журнала дают заниженное число. Тест строить на редких словах (df<=300) и брать пробы вразброс по всему журналу.
- 2026-11-10 — Архив с chmod 444 нельзя перезаписать: имя с точностью до секунды и chmod u+w перед записью, иначе PermissionError при повторном запуске в ту же минуту.
- 2026-11-10 — В multipart-запросе к Telegram граница и имя файла должны быть ASCII (заголовки кодируются latin-1); русский текст — только в caption/теле.
- 2026-11-10 — Проверки «в базе есть хоть одна строка» недостаточно: после хода в свежей среде в индексе 2 строки из 1303, и поиск молча работает по двум. Сверять покрытие с последним номером журнала.
- 2026-11-10 — Ротация: удалять манифесты надо по метке оставшихся архивов, а не по сравнению подстрок дат — иначе манифесты копятся.
- 2026-11-10 — Недельное расписание не отвечает требованию «каждый запрос»: писать запрос ПЕРВЫМ действием, ответ — последним, проверка — команда долг с кодом возврата.
